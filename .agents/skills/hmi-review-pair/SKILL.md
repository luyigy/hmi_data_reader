# HMI 逐图复核

用户已选定 Kimi 的左右对照方式。每张待复核原图生成一张合成图，不把原图和标框图拆成多条消息让用户来回比对。

## 图与文字

- 左边：原图，保留完整页面，不加框、不修字。右边：同一图、同一方向和比例，叠加识别框。标题写品牌、机台、页面、样本短 ID。
- 红色：有争议、需要用户裁定的字段，加字段名或问题编号。
- 蓝色：用户已确认的口径，本次无需重复确认；不能把模型高置信度当成人工确认。
- 橙色：不确定、空槽、遮挡或出画等需说明的区域。需用户作决定时，下方必须明确提问，不能藏在橙框里。
- 延续旧格式时可保留白色常规字段框：技术复核无疑问，但不能声称逐项经用户确认。图例写明所有使用的颜色，文字也表达状态，不只依赖颜色。
- 两张图下方直接放简短文字：难以靠框表达的语义、当前读值/单位/段归属、备选解释及编号问题。不要罗列所有已无争议字段。
- 无可见框的派生值、null 槽和共享框用下方文字说明，不虚构框；与红框编号保持一致。

本仓库已有生成器 `output/reviews/user-image-review-20260927/build_review_image.py`，可复用：

```bash
python3 output/reviews/user-image-review-20260927/build_review_image.py config.json review.jpg
```

配置字段：`image`、`title`、`panel_width`（默认780）、`exif_transpose`、`fields`（每项含 `name`、百分比xyxy `bbox`、`cls`）、`notes`和`questions`（字符串数组）。该生成器属于本地历史产物；其他机器无此文件时按本技能版式用现有 Pillow 绘制，不依赖历史 output 才能理解流程。

注意：生成器不会自动转换 bbox。原生坐标遇 EXIF=6、展示图顺时针90度转正时，框同步转为 `[100-y2,x1,100-y1,x2]`；其他方向按实际 EXIF 处理。原生图与显示图裁片须一致，不能只旋转图片。训练原图及原生坐标不被展示处理覆盖。

生成后实际查看整图：标题/图例不截断，数字可读，框不挡字，争议说明完整。图片过大时优先生成清晰 JPEG 或合理缩放，让话题里能直接预览；必要时另附高清文件。不要只发无法预览的标框附件。

## 裁定与入库

使用相邻的 `lark-task-topic-reply` 技能发送到当前任务话题。逐张确认；除非用户要求批量，不一次堆多张。用户确认后记录原话、样本 ID、时间和可获得的消息 ID；尚未回答不能自动放行。

保留屏幕原文与业务语义的区别。例如 2026-09-27 用户确认：伯乐 Z048 储料射退页 a4bb 的 **射退区“终止位置”6 mm就是松退距离**。可保留原字段键 `射退/终止位置`，在 observations 中写清语义；不能把储料三段终止位置15/60/100 mm也改成松退距离，更不能推广到所有页面的“终止位置”。

同步 annotation、批次 manifest、selection 和复核裁定记录；只有几何复核通过、留出隔离通过才加入显式复核训练清单。保留数值、单位和原图哈希，不因用户确认自动启动训练。确认后蓝框可沿用，已裁定问题不要再次当作待确认项。
