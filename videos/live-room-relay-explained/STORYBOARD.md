# 一张任务卡怎样安全走完

| 时间 | 画面 | 要点 |
| --- | --- | --- |
| 0–7 秒 | 标题 | 拟议流程，尚未上线 |
| 7–15 秒 | 任务卡三栏 | 目标、负责人、验收条件 |
| 15–23 秒 | 实施流程 | 代码提交可核对，任务防重复 |
| 23–32 秒 | 验收三栏 | 不采信口头通过，留检查证据 |
| 32–41 秒 | 通过或返修 | 新卡刷新预算，失败最多返修两次后暂停 |
| 41–50 秒 | 重启恢复 | 从持久状态找回并防止重复执行 |

六段中文配音与六个画面逐段对应。每屏的大字仍承载完整意思，方便在飞书聊天里静音观看。
