为什么以后跨仓也能复用这个办法？

默认从获批前置关系取交付，不让每个 Agent 编写一套路径约定。同仓多支线汇合时，平台核对候选包含所需提交，并检查来源；无法证明就停止，不拿“最新分支”凑数。

任务开始后固定输入版本。前置回修不会偷偷改变正在运行的任务；新尝试重新记录版本。源码缓存无活跃引用后才能清理，Git 交付和归档证据继续保留，后续仍可重建。

这里只读复用项目已有环境，不新建虚拟环境，不重复下载。模型认证各自隔离。服务使用临时数据，阶段结束、失败或取消后回收。
