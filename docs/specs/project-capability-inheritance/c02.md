## What to build

基于 C01 的可用项目能力契约，将其余任务启动、平台检查、独立验收及话题续接入口统一迁移。用户配置一次后，Reader 与 Mold 的派生工作区和后继任务无需逐节点补工具，能够并行推进，并保持用户隔离。

本票包含实际迁移、旧逻辑清理和完整演示，不只是测试票。完成后能单独演示跨仓继承与阶段切换。

## Acceptance criteria

- [ ] 所有相关入口使用同一有效能力解析结果；列明调用入口并删除重复解析与临时兜底，不留下两套授权源。
- [ ] 实施、检查、验收和原话题续接复用固定工具与材料身份，非 Git 验收目录也能使用正确资源，不逐节点重装或登录。
- [ ] Reader / Mold 同时运行，各自只写获准工作区；其中一个等人回答时另一个仍能推进，通过既有交付验收后后继自动接续。
- [ ] 只读验收与固定成果问答不修改源码或 Git；临时输出隔离，不因复用工具而放宽写权限。
- [ ] 新用户不能借用原用户权限；跨租户缓存隔离，撤销后新访问被拒绝，模型认证不暴露外部业务凭据。
- [ ] 项目配置或资源版本变化产生明确的新快照，不静默改变运行中的 attempt；不变版本可复用，已有材料补充记录仍可追溯。
- [ ] 保存候选和旧执行账本，明确兼容已有 Run；活动 writer 未退出时不迁移为第二个写入者。
- [ ] 输出真实跨仓演示与权限负例证据；列明线上部署范围及回退办法，不把测试替身成功当作线上完成。
