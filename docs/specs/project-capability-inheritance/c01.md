## What to build

用户在任务话题要求查找获授权图集或飞书表格中的图片，原执行者可在 Bubblewrap 内读取，选图后在绑定话题展示真实图片。R05 作为演示场景，代码适用于任何采用相同能力的项目。第一片受控部署后即可使用，不等待 C02。

项目配置、授权解析、资料提供、任务输入登记和回复投递均在本票内贯通；实现不是 R05 特判，也不先建设一个不可使用的框架。

## Acceptance criteria

- [ ] 管理员批准项目资源后，任务仅继承当前用户及获批范围允许的能力；修改工作区声明不能自行提权。
- [ ] 本地图集只读挂载，无整份复制；远端表格仅访问已批准范围，按需取得记录和图片，凭据不进入沙箱。
- [ ] 执行中追加查询所得材料有来源、哈希和新输入记录，后续轮次能读取，不静默改写已固定的材料。
- [ ] 重复获取复用缓存，缓存命中仍检查当前授权；跨用户、跨租户、任意 URL、路径与符号链接逃逸探针均拒绝。
- [ ] 原执行者声明展示图片后，宿主校验文件权限、类型与大小，幂等发送到任务绑定话题；回读确认图片和话题，不接受模型指定其他群。
- [ ] 卡片里的图片语法示例正常显示为文字；真实图片正确上传；图片处理失败仍保留文字答复，复现并消除旧 ErrCode 11310。
- [ ] R05 场景演示可找图、看图、回图；缺授权、缺工具或无匹配样本分别明确报告，不要求用户重复发图、不伪造业务验收通过。
- [ ] 通过实际 Bubblewrap 和测试话题验证完整路径。使用已有原会话接续实现，核对兼容部署版本；部署前不重启现有服务。
