## 验收项及验证命令

- [ ] 本地演示票只描述业务目标、仓库/基线、依赖、验收命令、默认环境画像及不变量，无平台准备步骤和会话恢复脚本。
- [ ] 夹具定义一个可读回结果的功能，例如输入表格生成带校验结果的报告；业务验收由独立检查命令读取产物，不能只测“安装成功”。
- [ ] 启动时缺少仓内依赖，Agent 自主安装并完成实际功能；遇到普通编译/测试错误能修复，平台不另建环境阶段抢先接管。
- [ ] 安装超出已批能力时走 S05；已有权限内的安装无需重复审批；能力阻塞保留事实，不自动改成继续工作。
- [ ] 本夹具的进度、提问、阻塞和提交验收通过结构化事件；自然语言仅用于说明。没有提交验收事件时不冻结/发布候选。
- [ ] 明确提交验收后平台冻结候选、独立运行业务验收、串行汇合；重放交付事件不重复集成或释放依赖。
- [ ] 手动创建的演示与本包手动实施相容，不发布 Issue、不自动导入本包；若演示产品任务图，使用独立明确授权的测试路线。

保留安全启动、权限、宿主限制、单写者、固定候选及独立验收；Agent 自主准备不意味着取消这些约束。
