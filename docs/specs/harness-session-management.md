## 最新范围与保留规则

用户追加要求：只做本机，按时间管理，所有会话保留一个月；超过一个月才允许用户删除，或需要管理员确认才能删除。远端管理移出本包。

以下具体口径是建议，尚未由用户确认：

- 一个月按连续 30 天计算，从最后活动时间起算，不从创建时间起算。最近仍使用的旧会话重新计算保留期。
- 超过 30 天才进入可清理候选，恰好达到边界仍受保护。到期只允许手动清理，不自动删除。
- 最后活动时间取可验证的原生记录活动时间、相关文件内容修改时间和平台最近使用时间中的最新值；扫描/大小采样时间不算活动。时间缺失或异常时禁止删除。目录内多份记录按最新活动计算，不能用目录自身 mtime 代表整组记录的活动。
- 管理员规则待定：“或者”可能指超过一个月后仍需管理员确认，也可能指允许管理员提前删除。建议首版采用“超过 30 天 + 管理员确认”，近期历史不提供强制删除例外；复用现有管理员权限，不新增跨人审批流程。
- 超过保留期不代表会话不再使用。运行中、排队、当前绑定和等待恢复等保护仍适用，管理员确认也不能绕过活动保护。执行时重新核对活动时间和引用状态。

## 建议的用户体验

建议首版增加独立的“历史会话”页面，以本机服务端允许访问的运行身份及目录为范围。

1. 查询：按 harness、最后活动时间及“保留期内／到期但受保护／可清理／状态未知”筛选。
2. 查看：展示会话身份、项目/关联任务、最后活动时间、已测字节数、采样时间和保护原因。
3. 清理：勾选单条或批量选择超过保留期的候选，先预览固定的会话清单、数量、已知文件字节数和排除原因，再由有权用户确认执行。执行时不重新展开筛选条件。

建议首版暂不包含正文预览/全文搜索、收藏、归档、回收站恢复、自动清理和独立飞书管理交互。以上是缩小工作量的建议，删除规则定稿前不执行真实清理。

## 管理对象与覆盖范围

平台 TaskSession、TaskRun、聊天消息和 harness 原生记录分别存储。首版“删除会话”指清理选定的原生历史，并更新平台的可续聊状态；不会顺带删除平台任务、审批及执行证据，也不会撤回飞书消息。若用户要求同时清除平台聊天正文，应另列明确操作及保留范围。

默认显示平台可关联的原生会话。经授权扫描目录后发现的平台外历史单独标为“未关联”，不能因没有数据库引用就认定可安全删除。无法确认归属或活动状态时只读展示。无权限、不支持、离线、缺失和空目录必须区分，未知大小不能显示为零。

会话身份须包含执行主机、运行身份/存储根、harness、原生 ID；同一 ID 在不同主机或运行身份下不能合并。同一原生会话被多个 participant 引用时只计一次，并展示所有关联。Pi 的续聊对象可能是一整个目录，界面必须说明其中有多份 JSONL，避免显示单条却删除整组。

| 对象 | 可复用证据 | 拟定顺序与未决事项 |
| --- | --- | --- |
| 本机 Codex | 指定 rollout JSONL 的定位、身份头及大小读取 | 首批；补查归档历史、索引和相关存储，完整盘点后才确定删除范围 |
| 本机 Kimi Code | 指定 session 目录及其原生子记录的大小读取 | 首批；核验目录元信息、索引及子会话归属 |
| 本机 Pi | 指定 session-dir 内 JSONL 的大小读取 | 首批；核验目录与其中单份会话的管理边界 |
| 本机 Antigravity | 指定 SQLite DB 和 WAL 的大小读取 | 首批；核验连接关闭、WAL/SHM 及其他关联状态的一致性处理 |
| SSH Pi | 远端指定会话的只读采样 | 不在本包范围 |
| Remote Runner Pi | 完成帧回传指定会话大小 | 不在本包范围 |
| 其他已注册本机 harness | 执行适配器和部分续聊身份 | 单独核验原生管理能力；未适配时显示不支持及原因 |
| Gateway | 远端执行与聊天记录 | 不在本包范围 |

“有大小读取器”不表示“删除文件即完成删除”。每种格式须核对关联索引、附属文件、子会话和恢复行为后开放删除按钮；不把历史目录之外的凭据、配置或项目代码纳入清理。

## 删除行为约束

- 查询和删除均在服务端按实际用户、主机及存储范围鉴权，不接受前端任意路径作为目标。真实路径与文件身份重新校验，拒绝越界、符号链接及预览后被替换的对象。
- 正在执行、排队待续聊、当前房间绑定、等待审批/恢复或被保留策略保护的会话禁止直接删除，并展示原因。检查覆盖所有引用；平台外进程的活动状态无法确认时保持只读。
- 删除与派发/续聊共用同一会话的互斥或等效机制，避免“检查时空闲、删除时已启动”。需要与外部 CLI 协调的适配器在无法可靠排他时不开放删除。
- 平台先持久记录清理操作和状态，阻止目标被新执行选中，再执行存储操作并回写结果。不能只移除最近一条 participant 的 ID：旧记录仍可能被续聊回退逻辑命中。
- 建议首版仅提供确认后的永久删除，明确告知不可恢复；回执不把逻辑文件长度等同于实际磁盘释放量。各格式内部保证一致性所需的临时处理不等于面向用户的回收站功能。
- 重复请求、服务重启及批量部分失败都按操作 ID 对账。不假报删除成功；删除后保留最小操作审计，不保留额外正文副本。
- 正在删除及已删除的会话都不可再被续聊选中。删除范围不包括供应商云端副本。

## 可讨论的交付切片

1. **本机历史查询与到期筛选**：上述四种本机 harness 的允许范围扫描、去重、分页、最后活动时间、保留期状态、大小与来源展示；未关联记录单独展示。
2. **本机到期会话清理**：权限校验、删除预览、单条/批量永久清理和操作回执；覆盖保留期复查、多引用与续聊互斥。

按本机四种 harness、已有管理员身份可复用且不增加跨人审批流程的范围，初估两个 Slice。若原生索引一致性或外部 CLI 活动保护需要额外机制，应在定稿时将第二片拆分，预计可能增至三个 Slice；不能把未适配的删除能力计作完成。Slice 数量是交付边界估计，不是 Session 数或工期承诺。

各 Slice 均包含界面、服务端行为及对应自测。具体依赖、保留期口径、管理员规则和验收角色在讨论后定稿；按仓库默认任务图流程形成 Spec/tickets 和真实路线卡，经用户确认后实施。不为本包创建旧 PLAN/HANDOVER 接续链。

## 验收关注点

- 同 ID 跨主机/运行身份隔离；多个平台引用去重；Pi 多文件和 SQLite WAL 的统计口径明确。
- 大目录扫描有分页、数量/时限控制；权限不足、坏文件和重复身份可诊断，不影响其他来源查询。
- 当前/排队/等待恢复会话不可删；删除与新执行竞争时只有一方获得使用权；被删除记录不会被历史回退再次续接。
- 预览后文件变化、路径穿越、符号链接、跨用户访问、重复确认和部分删除失败均能拒绝或正确对账。
- 30 天边界、创建早但近期使用、目录内部分记录更新、时间缺失/异常、预览后重新活动均正确处理；管理员身份不能绕过活动保护。
- 永久删除结果可复核；平台任务、审批证据、凭据和项目文件未被意外清理。
