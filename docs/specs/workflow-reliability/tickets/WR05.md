# WR05：重启后接续当前阶段且不重复启动写入者

状态：隔离回归与独立评审已通过，协调器和任务进度卡服务已更新；实际 R01 接续验证中。

远端单据：[IKNBDS](https://gitee.com/luyi1678/agent-platform-v2/issues/IKNBDS)；父规格：[IKNBDN](https://gitee.com/luyi1678/agent-platform-v2/issues/IKNBDN)。

## What to build

协调器重启时核对已登记的 TaskRun 与实际写入者，原进程存活就继续观察，确认退出或被可靠隔离后再从持久阶段接续。

## Acceptance criteria

- [ ] 执行开始前登记 TaskRun 与所有权，重启恢复不单凭内存集合或超时猜测进程已经结束。
- [ ] 旧写入者存活时，新 Agent 启动次数为零；确认退出后自动领取并接续，不重复实施已完成阶段。
- [ ] 过期 worker 在 Git 提交、引用更新及状态写入前无法继续使用旧执行权；不把租约到期本身当作进程隔离。
- [ ] 实现、架构及验收阶段均覆盖重启场景，超时回收入口统一迁移，不遗留只转 attention 的默认出口。
- [ ] 证明不重复集成、不重复启动联调服务，旧报告、候选提交和补充文件仍可读取。

## Blocked by

- WR02

## 执行方式

本票按 poteto-mode 的 Bug fix 流程实施：先复现真实故障并保留红色测试，再沿已确认架构修复，运行实际行为回归后交独立验收。技能及项目适配在每个新 Session 显式加载。平台负责批准路线、依赖、受控提交和集成；Agent 不自行扩大权限或派发其他票。

会话结束、代码有变化或结果格式可解析均不等于验收通过。保留原审批、历史证据、原仓文件和既有项目环境。超时后先核对现有操作，避免重复执行。
