# HANDOVER · 管理员用户管理界面与API交付

## 完成内容

- 新增管理员用户 API：`GET/POST /api/admin/users`、`DELETE /api/admin/users/:id`、`POST /api/admin/users/:id/reset-password`。所有处理器均调用 `requireAdmin()`，并同时登记在中央 `auth-routes` 管理员策略中。
- 创建用户固定为普通用户角色，校验用户名、显示名和至少 8 位密码，并禁止与 env bootstrap admin 重名；密码继续复用现有 PBKDF2 哈希实现。重置密码只写入新哈希，不返回密码或哈希。
- 删除用户前检查目标存在，并阻止数据库管理员删除当前登录账号。用户资源按 S02 的 `onDelete: SetNull` 保留为仅管理员可见的无主资源。
- 新增 `/admin/users` 极薄管理页面，支持列表、新建、重置密码和删除；侧栏入口仅对管理员显示。
- 新增单文件自检及 npm script，覆盖中央管理员路由、非管理员 403、列表、创建、密码哈希重置与删除。
