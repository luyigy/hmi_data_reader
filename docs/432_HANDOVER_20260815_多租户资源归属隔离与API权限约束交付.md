# HANDOVER · 多租户资源归属隔离与API权限约束交付

## 完成内容

- `Task`、`LiveRoom`、`RemoteNode` 新增可空 `ownerUserId`、`User` 关联与索引；历史空 owner 资源仅管理员可见，新建 Task/LiveRoom 写入当前数据库用户，Live Room 派生 Task 同步继承 owner。
- Task、Live Room、Remote Node 的列表、详情与嵌套操作按 `admin ? unrestricted : ownerUserId` 过滤；跨用户资源统一返回 404，Task Room 消息入口也校验其关联 Task owner。
- 普通用户只能选择和执行自己名下 RemoteNode；Platform Local、全局 Gateway、全局 RemoteHarnessHost 与 standard 本地执行返回 403。管理员保持全局访问。
- Live Room 可用 agent 目录对普通用户仅暴露其 RemoteNode；RemoteNode 列表按 owner 过滤。
- 新增跨用户负向测试，覆盖列表 owner 条件、跨用户详情、Platform Local 禁止与他人 RemoteNode 禁止。

## 数据迁移

- 新增并已在本地 PostgreSQL 应用 `20260815150000_add_resource_owners`。
- 本地库此前存在两处“列已存在但迁移记录未完成”的漂移：`specialty` 与 `tier`。核对对应迁移均为单列添加后，已标记 applied；其余待执行迁移及本次迁移随后全部成功，`prisma migrate status` 为 up to date。
