# 伯乐 S3 拒识口径与定向收口计划

## 1. 审批结论

继续使用 PaddleOCR + 模板链路，不建设 VLM fallback。现有 24 个不匹配中，18 个来自 `bole_Z047_20250516_rank16`：真值标记 `allow_auto_import=false`，流水线以 `status=reject` 正确阻止入库，但旧口径仍把该图 18 个真值数值计入准确率分母，使安全行为被记为数值缺失。

本计划批准将“正确拒识”从数值准确率与完整率计分中剥离，并以独立拒识正确率硬门禁防止通过滥拒绝抬高数值指标。剩余真实提取问题限定为 3 张图 6 个字段，做两处定向根因修复后只运行一次现有 20 图验收。

## 3. 验收口径决策

### 3.1 数值与完整率计分

- `allow_auto_import=true` 的图片全部进入数值准确率和字段完整率分母。
- `allow_auto_import=false` 且提取 `status != ok` 的图片视为正确拒识，其数值元素不进入上述两项计分。
- `allow_auto_import=false` 但提取 `status=ok` 的错误放行图片仍进入数值计分，同时拒识正确率失败；不得通过排除负样本掩盖错误放行。
- 报告必须同时给出全量真值元素数、计分元素数、被排除图片和元素数，旧口径结果可追溯，不得只输出修订后的高分。

### 3.2 三项硬门禁

| 指标 | 门槛 | 空分母规则 |
|---|---:|---|
| numeric_accuracy | >= 0.95，容差 ±0.5 | 空分母 FAIL |
| error_auto_import_rate | 严格 = 0 | `status=ok` 元素空分母 FAIL |
| rejection_accuracy | 严格 = 1 | `allow_auto_import=false` 图片空分母记 N/A，不得宣称 PASS；本批分母应为 1 |

其余控制器分类准确率、页面分类准确率、字段完整率、可自动入库比例继续如实报告。拒识正确率是新增安全指标，不替代错误自动入库率。

## 4. 切片

### S1：口径实现与两处定向修复

1. 在现有验证器内实现 §3 口径，保留全量与计分口径的可审计计数。
2. 修复 B_AND_R rank12 第 4 列关联根因，不改变其他列和家族行为。
3. 修复 KEBA Z001 右侧下料口/待机温度单值区的漏检与整数错认根因，不做单图常量补丁。
4. 运行最小聚焦检查，但不生成最终 20 图验收报告。

**停止条件**：口径防滥拒绝检查通过；3 张目标图的 6 个字段获得根因级修复证据；既有家族边界未被扩大；S1 HANDOVER 落盘后停止。任一根因无法局部修复则准确记录并停止，不进入 S2。

### S2：一次性 20 图验收与 013 S3 收口

1. 冻结 S1 的实现和计分口径，使用现有 `ground_truth/bole_temperature/` 20 图运行一次完整链路；看过结果后不得再调参数或改口径。
2. 报告六项原指标、拒识正确率、整体及 KEBA/B_AND_R 分家族分子分母、逐图不匹配、全量与计分口径差异。
3. 三项硬门禁全部通过才判定伯乐 S3 PASS；任一失败则判定 FAIL，并把残差和下一步选择交回审批，不追加调参轮次。
4. 创建合同合规 HANDOVER，回到 `docs/013_PLAN_20260730_主力家族温度页模板.md` 的 S3 收口；不得自动启动 S4。

**停止条件**：20 图报告与 S2 HANDOVER 落盘，PASS/FAIL 明确，013 S3 状态得到准确衔接后停止。

## 5. 风险与控制

| 风险 | 控制 |
|---|---|
| 排除拒识图制造假高分 | 仅排除真值负样本且实际非 `ok` 的正确拒识；独立拒识正确率严格为 1；错误放行不得排除 |
| 单一报警样本不足以证明泛化 | 报告明确分母仅 1，本结论只覆盖当前 PoC；不宣称生产可靠性 |
| 继续针对 20 图过拟合 | 修复限定已定位结构根因；S2 只跑一次，看结果后冻结 |
| B_AND_R 修复影响已通过样本 | S1 聚焦检查其他 B_AND_R 列，S2 分家族报告；不以整体值掩盖回退 |
| KEBA 单值区修复误吸邻近数字 | 使用标签、区域与字段关系约束；不得用图片名或固定答案特判 |
| 大文件继续越过阻断线增长 | 只允许局部替换或净不增长；需要拆分时另行立项，不在本计划夹带 |
| 安全门禁被数值准确率替代 | `error_auto_import_rate=0`、非空 ok 分母与 `rejection_accuracy=1` 均独立判定 |

- S1：最小验收口径改动、两处定向根因修复、最小聚焦检查、HANDOVER。
- S2：一次 20 图整体/分家族报告、拒识安全指标、013 S3 收口 HANDOVER。
- 不下载新附件，不更新飞书，不重启服务，不执行生产写入，不建设 VLM fallback。
- 任一 Slice 完成即停止；不得自动开始下一 Slice 或 013 S4。
