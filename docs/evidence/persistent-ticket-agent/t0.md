## 运维入口

`npm run task-graph:control -- --run-id=<实际路线> --action=pause --request-id=<唯一请求> --actor=<真实本机操作员> --reason=<原因>`。

resume 需要新的明确请求；回放旧请求不能覆盖后来暂停。命令返回每个执行的 Writer 观察，不将 alive/unknown 宣称成 exited。此入口是受信任宿主运维工具，不向模型沙箱暴露平台数据库凭据。用户接口的鉴权与总览操作在 T3 接入。

暂停由现有 Run.status 的 paused 运行控制值表示，不修改数据库 schema、不创建第二套任务状态机。普通状态汇总不覆盖暂停。新预留与用户控制共享事务锁；进程停止交给持有 Manager 句柄的 Coordinator。已发生的合法结果可以保留，但后继释放和新的执行必须尊重暂停。
