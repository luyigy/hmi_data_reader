直接故障

技能检查是 Node 脚本，但 Sandbox 构造仍触发 Python 环境推断。验收目录非 Git，技能预检又漏传已知主仓身份，于是从只读目录扫出多个环境并报错。

结构性问题

已知资源在 claim / 阶段入口反复准备。输入传播差异会在每次重复过程中重新触发故障；条件扫描又出现额外放行。生命周期上提可减少重复入口，但首次准备仍须正确传主仓身份。

pytest 通过只代表专项测试。验收 Agent 未实际完成验证，所以整票未通过。四次失败来自已保存的 TaskRun 与 verification_failed 事件；条件扫描误判恢复的具体输入差异仍待回归锁定。
