# 207_HANDOVER_20260718_全员会话重置

## 任务类型

feature / bugfix

## 所属主线

临时插队；阻塞 Feishu 多 Agent 房间的上下文重置操作，必须立即修。

## 为什么做

原有 `/ap new-session` 默认只重置当前 speaker。用户需要一次为房间内全部可回复 Agent 建立 fresh session。

首版 `/ap new-session all` 按成员串行启动，并沿用“继续当前工作”的单成员 bootstrap prompt，导致首个 Agent 实际执行旧任务时整条 Feishu 命令长时间无回执。

## 修改内容

- `src/lib/feishu.ts`
  - 新增 `/ap new-session --all`，同时支持 `/ap new-session all`。
  - 一次旋转共享 `TaskSession`，写入全局 reset marker。
  - 清空房间内全部可回复 Agent 的旧 thread 状态。
  - 并发启动各 Agent 的 fresh session。
  - 全员模式只要求确认新 session ready，并明确禁止继续旧任务、调用工具或修改文件；单 Agent 模式保持原行为。
  - 帮助文本补充 `--all`。
- `tests/feishu-mode-command.test.ts`
  - 增加 `--all` 命令解析检查。

`src/lib/feishu.ts` 已超过 1000 行，本次仅做与命令直接相关的窄范围修改；后续若继续扩展 Feishu 命令，可将 new-session handler 与 prompt helpers 整体提取为独立模块。

## 对主线的影响

补齐 Feishu 多 Agent 房间的显式全员上下文重置能力，不改变无参数命令默认选择当前 speaker 的行为。
