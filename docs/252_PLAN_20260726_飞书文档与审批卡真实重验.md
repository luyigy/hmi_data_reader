# PLAN · 飞书文档与审批卡真实重验

## 目标

用新的 Git 事件完成一次真实闭环验收：

1. watcher 导入本 PLAN 并生成飞书文档；
2. watcher 发送包含文档链接和审批按钮的卡片；
3. 真人批准后只启动一次后续 Session。

## S01：真人验收

核对飞书文档和审批卡，等待真人点击批准，再核对 cursor、审批终态和后续 Session。
不得代替用户点击，不得重复发送审批卡。

## 验收标准

- 飞书文档可打开，内容来自本 PLAN 的已提交版本。
- 审批卡包含文档链接及批准、拒绝、修改按钮。
- 真人批准后只发生一次状态转换和一次后续 Session。
