## 配置与运行边界

Reader 验证台进程新增 HMI_LAB_PROXY_KEY；Web 后端配置 HMI_VALIDATION_API_KEY 为相同随机密钥，HMI_VALIDATION_SERVICE_URL 为验证台根地址，例如 http://10.144.144.5:8766。密钥仅进入两服务私有环境，不发送给浏览器或写入 Git。
HMI_LAB_PASSWORD、HMI_READER_URL、HMI_API_KEY、HMI_LAB_DATA_DIR 沿用原设置；CLI 非回环监听仍需 HMI_LAB_PASSWORD。验证台保持单进程，不能启动多个 worker 共写本地 JSON。
手机无需隧道，但 Web 服务端仍必须能到达该地址；通过可信隧道或 HTTPS 连接，不直接公开验证端口。
当前运行的 8766 进程仍是旧进程；本次只启动并结束了回环 18766/18767 隔离测试进程。
