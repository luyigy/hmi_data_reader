# 本机历史会话管理首版

2026-10-30，Feishu DM 08a216 用户要求恢复此前讨论并上线会话管理，减少历史记录占用。本次直接实施和部署沿用该授权，不创建自动任务路线或 PLAN/HANDOVER 接续链。

## 本次交付与边界

- 管理员导航增加“历史会话”，地址 `/admin/session-history`。服务端管理员鉴权，普通用户和未登录用户不能列举或清理本机其他人的原生历史。
- 查询共享与配置的 Codex/Kimi/Pi/Antigravity 目录、聊天室专用 Codex 目录，以及任务隔离 Codex/Kimi 运行目录；去重身份包含主机、系统用户、存储根、工具和原生 ID。按工具、保留状态筛选、分页，展示项目、平台引用、已测字节数和活动时间。
- 原讨论未最终确定管理员例外。本次采用已告知用户的保守首版：最后活动严格超过连续 30 天、管理员预览后明确确认；不自动删除、不提供管理员提前删除。活动时间考虑原生元信息、文件修改时间和平台实际使用时间，不用扫描时间续期。
- Codex 使用本机 `codex --no-daemon delete --force <UUID>`，由原生工具处理索引一致性。已在隔离临时目录验证原生删除成功，未删除用户真实历史。
- Pi 只管理平台专用 session-dir；多份 JSONL 整组展示，整组保留期。确认时校验目录及全部文件身份、大小和时间，先移动至同根暂存名再核对，随后删除确认清单中的文件。异常时保留未删除文件供核对。
- **Kimi 和 Antigravity 仅查询，未开放删除**。Kimi 的索引与子会话、Antigravity 的摘要 SQLite 与原生进程排他清理尚未完成验证。不能把目录大小采样或移除单份文件当成完整删除。
- 未适配 Claude/Claude Haha、DeepSeek、Gemini CLI 的历史清理；远端、平台外 Pi 默认目录、未登记自定义 home 和未扫描的 Codex 分页存储也不属于本次覆盖范围。页面明确列出未覆盖项，不把缺失或未知当零。

## 执行保护

- 未关联记录、同 ID 多处存储、当前 TaskSession、聊天室原生绑定、等待恢复/处理、任务图未集成、运行或排队记录均保护。读取失败或扫描超限时拒绝清理。
- 预览绑定实际管理员和固定会话清单，10 分钟有效。确认重新核对文件、保留期和全部平台引用；客户端不能传任意删除路径。
- Codex/Pi 原生执行和清理共用跨进程共享/排他锁；兼顾常规 harness 和旧直接执行入口。清理期间不启动同工具运行；检测到同用户的原生工具/后台进程时拒绝，不代用户终止进程。平台外历史保持只读；本功能不是对不遵循平台锁的任意外部 CLI 的统一调度器。
- 删除前持久化操作状态和原生 ID 墓碑，并将所有匹配 participant 的续聊标为失效。历史回退和原生 resume 都拒绝已删除/待核对的身份。
- 状态和结果位于 `~/.agent-platform/session-history/`（可由 `AP_SESSION_HISTORY_STATE_ROOT` 指定），权限受限。重复确认只读原回执，不重放部分失败的删除；中断或失败保持阻断，需人工核对操作 ID，不自动清除墓碑。
- 平台任务、审批、聊天、执行账本、工具配置、凭据、项目代码和供应商云端副本均不在删除范围。展示记录逻辑字节数，不承诺等量实际磁盘释放。

## 生效与运维

查询页随本仓 Web 服务加载新源码生效。清理默认关闭，只有执行服务完成重载才写入启用标记，避免旧运行器绕过新锁。

`node scripts/enable-session-history-when-idle.mjs` 等待 TaskRun、Job 和 Delivery 空闲，再重载五个现有平台服务并核对 PID，最后启用清理。等待超过 20 分钟则退出且保持关闭。不会自动删除历史，也不会强停原生 CLI/后台 daemon。

本首版不是“全部工具永久删除已上线”；剩余删除适配和平台外历史管理仍需继续实施。首次真实清理必须由管理员在页面核对具体预览后确认。

原生格式核验参考：本机 Codex `delete --help` 与隔离删除探针；Kimi [数据位置文档](https://moonshotai.github.io/kimi-code/en/configuration/data-locations.html)及[原生 Server API](https://moonshotai.github.io/kimi-code/en/reference/server-api.html)。Kimi 不能仅凭移除 sessions 子目录就宣称索引与子会话清理完整。

首次线上查询发现测试 Agent 的 `CODEX_HOME` 指向本房间专用目录，而 Web 服务使用共享默认目录，不能把两者的单次统计互当全量。已补齐默认与配置目录的并集，并登记现有派发代码使用的 `/data1/.agent-platform/codex-rooms/`，覆盖 33 个聊天室目录。相同根只扫描一次。
