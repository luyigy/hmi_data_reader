# HMI-Reader 仓库未提交变更全面盘点与收口交接

## 1. 概述与目标

对 `hmi_data_reader` 仓库此前遗留的全部未提交改动进行了完整盘点、影响面评估、测试验证及归档收口。本次提交将所有既有未提交代码、新增脚本、安全兜底规则、数据集契约版本升级、测试用例以及 GitNexus 工具集成一并规范入库。

---

## 2. 未提交变更分类盘点

### 2.1 服务与运维加固 (Service / Security / Ops)
- **`hmi_service.py`**：
  - 新增 `CORSMiddleware`，支持通过 `HMI_CORS_ORIGINS`（默认 `*`）配置跨域资源共享；
  - 新增可选 Bearer Token 认证中间件 `authenticate_recognition`（通过 `HMI_API_KEY` 环境变量启用，未设置时保持现有开放行为，不破坏已有客户端调用）；
  - 异常信息脱敏：将 500 错误响应从直接透传底层异常堆栈简化为标准 `"Internal recognition error"`，防止内部环境信息泄露。
- **`docs/hmi-gpu-service.service`**：
  - 更新 systemd 服务单元配置，通过 `scripts/run_service.sh` 统一启动，并显式指定 `HMI_HOST=0.0.0.0` 和 `HMI_PORT=8765`。
- **`scripts/run_service.sh`**：
  - 新增服务启动脚本，封装 `CUDA_VISIBLE_DEVICES`、`HMI_HOST`、`HMI_PORT` 环境变量，自动拉起 `.venv/bin/uvicorn hmi_service:app`。
- **`.gitignore`**：
  - 统一忽略 `output/` 批量运行与实验产物目录，避免瞬态测试文件污染版本库状态。
- **`README.md` & `CLAUDE.md`**：
  - 新增 `scripts/explain_case.py` 单图解释与验收工具使用说明；
  - 同步 GitNexus 符号与流程索引统计数据。

### 2.2 确定性提取规则与安全兜底 (Deterministic Extraction & Guardrails)
- **`scripts/contract.py`**：
  - 增加空间通用布局识别支持（当 `extraction_detail.engine == "spatial-kv+dynamic-grid"` 时，将 `layout_variant` 解析为 `spatial`）；
  - 空间通用提取对应 `profile_id = "generic.spatial"`，赋予 `candidate` 状态并施加置信度上限限制（`min(confidence, 0.40)`）。
- **`scripts/extract_families/est_temperature.py`**：
  - 针对 EST 控制器温控设定行多位连续数字粘连情况（如 `\d{9,27}` 且长度为 3 的倍数），增加按 3 位拆分为温度设定值的自适应算法；
  - 记录 `SET_ROW_SPLIT` warning 并动态收紧当前温度吸附间距。
- **`scripts/extract_families/fanuc.py`**：
  - 增加 `DROP_PORT_CURRENT_MISSING` 安全 warning（当落料口有设定温度但当前温度缺失时触发，拦截自动入库，降级为 `review`）。
- **`scripts/extract_families/tact_hot_runner.py`**：
  - 增加 `CHANNELS_INSUFFICIENT` 安全 warning（当热流道总通道数 >= 6 但有效识别通道数 <= 3 时触发，防止不完全识别错误放行）。
- **`scripts/explain_case.py`**：
  - 新增 CLI 单图诊断工具：直接复用已有 OCR sidecar JSON，追溯图片路由、命中模板、拦截 warning、提取字段及与真值（truth.yml）逐字段比对结果，无需重复跑 GPU OCR。

### 2.3 VLM 离线语义映射与评测工具链 (VLM Offline Mapping & Harness)
- **`scripts/vlm_qwen.py`**：
  - 支持 `supplements` 增补 token（如 `rate_cell` 补充 OCR 覆盖）；
  - 确定性处理多级保压段序（`screen_left_to_right` 确定性逆序映射）与禁用槽位过滤；
  - 增加严格的业务行锚点校验，禁止无标题/无单位孤立行被误映射。
- **`scripts/vlm_text_eval.py`**：
  - 新增 `_unresolved_request` 构造函数：仅向 VLM 输入当前页未解决字段和对应 OCR token，剔除已解析字段；
  - 双路字段合并与 hybrid 门禁状态裁决（有 unresolved 或 VLM 参与保持 `review`，空字段为 `reject`）。
- **`scripts/vlm_eval.py`**：
  - 新增基于 Qwen3-VL 的真值数据集回放评测脚本，产出 `results.jsonl` 与字段级 `summary.json`。

### 2.4 数据集契约版本升级与真值校正 (Datasets & Truth Manifest)
- **数据集元数据升级**：
  - `datasets/calibration/`、`datasets/holdout/`、`datasets/regression/` 下全部 119 个 `.meta.json` 文件的 `contract_version` 统一升级至 `2.11.0`。
- **DEMAG 多级保压真值校准**：
  - 更新 DEMAG 多级保压 4 个 case（`holding_Z002_ab30f6f6`、`holding_Z002_barspez_65f50de2`、`holding_Z002_1785755259328`、`holding_Z002_e4d130e8`）的 `allow_auto_import: true` 及对应 truth sha256 校验和。
- **`datasets/release_manifest.json`**：
  - 契约版本更新至 `2.11.0`，全量数据集分区（calibration: 62, holdout: 46, regression: 3）校验通过。

### 2.5 辅助工具与代码智能 (Code Intelligence & Tooling)
- **`.claude/skills/gitnexus/`**：
  - 包含 GitNexus 完整的代码图谱探索、影响面分析、调试与重构技能文件，契合 `AGENTS.md` 规范。
