# PLAN · 飞书文档与审批卡真人验收

## 目标

用本 PLAN 做一次真实飞书闭环验收，确认 workflow watcher 能：

1. 从目标 Git commit 导入本 PLAN，生成可打开的飞书文档；
2. 向配置的审批会话发送带“批准 / 拒绝 / 修改”按钮和文档链接的审批卡；
3. 在真人点击“批准”后，只启动一次下一 Session。

本次只验收现有能力，不修改代码、不重复发卡、不代替用户点击。

## S01：核对真人验收结果

1. 核对本 PLAN 对应的飞书文档 URL、审批卡和审批状态。
2. 核对文档正文来自本 PLAN 的已提交版本，卡片中的链接可以打开。
3. 核对真人点击“批准”后只产生一次状态转换和一次后续 Session。
4. 把实际结果写入一份 REPORT；如发现失败，只记录现象和证据，不在本计划内修复。

## 验收标准

- 飞书文档标题和正文与本 PLAN 一致。
- 审批卡包含文档链接及“批准 / 拒绝 / 修改”按钮。
- 点击“批准”后卡片进入终态，重复点击不会重复启动 Session。
- REPORT 记录通过项、失败项及相关 run、commit、文档 URL。
