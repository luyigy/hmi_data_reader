## 发现和已修正的问题

1. **日精二代两段保压被套用了单段规则。** 四份Tp1原来都是null，实际清晰可见：Z019=2.00、Z009=1.50、Z025=1.80、Z012=2.00 s。已修正字段与holding_time说明；缺实际充填时间影响末段推导，不影响读出第一段。单段Z015的Tp1仍保留未知。
2. **佳明旧布局红字实际耗时混入监督设定。** 已确认的1547/fbd9删除射出区红色s监视列，保留独立射出时间和保压黑字时间。空白设定槽仍保留null及对应bbox。468c同类错误列入技术返修。
3. **德马格两张工艺优化页把禁用值当成有效设定。** 预塑前松退速度/位置、未勾选的压力/时间转换条件共8个value改null，保留启用标志与可见残留说明。Z005页面直接显示预塑速度mm/s，按图保留，无需要求用户确认是否改成U/min。
4. **212个bbox发生修正。** 旧框包含错段、错行、漏数字与框到实际值。已确认14张按原图坐标重定位并检查逐字段裁片。范围合法只能证明JSON坐标可解析，不能证明框住正确值。
5. **伯乐Z001射胶页另有设定/实际混淆。** 待复核60da的转保压螺杆位置从38.50改为右侧白框36.00 mm；其他段序疑点仍未放行。全部新草稿累计13个value修正（含该条、四个Tp1、八个禁用值）。
6. **德马格多级保压时间归属已有用户真值。** 查阅 `ground_truth/demag_holding/holding_Z002_photo_1784721642626.truth.json`，王为2026-08-05确认时间行是相邻压力点间时长，非累计时刻。3666图2s/1s可直接确认；删除“末段持续到冷却结束”的无充分依据断言，不重复问用户。
7. **EXIF方向问题。** 新批468c、a4bb、8726带orientation=6。读图工具显示正向，但 `train_small_sample.py` 目前直接 `Image.open(...).convert('RGB')`，没有方向归一化。前两张语义可确认却尚不可训练；8726同时有Q3业务争议。不可只修改框范围或移除EXIF标签来伪造修复。
