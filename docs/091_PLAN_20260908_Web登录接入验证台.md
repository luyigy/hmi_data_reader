## S01 支持 Web 同域访问

- 目的：复用验证页面，移除手机隧道依赖。
- 结果：可信代理传递用户身份，用户批次隔离，原独立入口继续可用。
- 实现：共享密钥与用户 UUID 校验、按用户文件目录、相对静态资源与 API 地址。
- 边界：仅 validation_lab 和聚焦测试，不修改识别算法及已有未提交文件；跨文件是一个完整访问链路，不增加数据库或依赖。
- 验收：伪造身份拒绝、跨用户列表/读写/照片/下载隔离、旧入口回归、Web 代理联合检查。
- 前置与停止：配对 Web 代理；未知风险通过调用检查与测试记录；完成代码和交接后停止，不扩展识别或实际写入。
- 交付：提交、部署说明、HANDOVER 和明确的线上验收限制。
