- 用户 2026-08-01 明确优先级：射胶/保压等核心工艺参数比温度页更重要，温度页链路已成熟（工具箱齐全），转进本线。

- 51 台机台家族已全部建档（029/030），本线直接受益——跨家族页面结构差异已有预判基础。

## 2. 切片

- **S1（只读盘点）**：统计「成型条件-射出/保压」附件按品牌×机台的记录/附件分布，落 `output/inj_pool_inventory.json`；不下载任何附件。
- **S2（选机与候选）**：按记录量与家族覆盖选 2-3 台（优先已有温度页模板的家族主力机，便于对照），出候选清单 PENDING_USER_APPROVAL。
- **S3（下载去重）**：批准后下载 ≤30 条 + SHA-256 去重。
- **S4（VLM 草稿）**：≤18 份，每 turn ≤6 张；先读 2-3 张摸清各家族射保页结构再批量。
- **S5（核验表+真值）**：飞书核验表 + 自动整批接受（降级口径 + 事后否决）。
- **S6（模板与验收）**：射保页模板（归一化坐标）+ 提取分支进 `scripts/extract_families/`，18 图三门禁验收（numeric ≥0.95 / error =0 / rejection =1 或 N/A）；FAIL 如实报告不追加调参。
- **S7**：HANDOVER 收口。
