# PLAN · 重启后完整角色工作流验收

## S01：无改动端到端验收

服务重启后，用本次新提交的 PLAN 验证从 watcher 发现、人工批准、Live Room 角色串行执行到终态落库的完整流程，不实施业务功能。

验收范围：

- watcher 发现本 PLAN 并发送审批卡；批准后无需补发 `/run feature` 或 `/run debug`。
- 系统依次执行实施计划、计划审查、计划定稿、测试方案、功能实施、代码审查、验收测试、最终总结 8 个阶段，且成员与 planner、reviewer、tester、implementer 角色匹配。
- 计划审查和代码审查仅输出 `APPROVED`，验收测试仅输出 `PASSED`，功能实施输出 `NO_CHANGES` 和“修改文件：无”。
- 成功时 dispatch 进入 `completed` 并发送完成消息；失败时进入 `failed`、停止后续阶段并报告失败位置。

禁止修改文件、提交 Git、重启服务或执行耗时测试。任一阶段顺序或角色不符、需要手动启动工作流、产生仓库改动或终态错误，均视为验收失败。
