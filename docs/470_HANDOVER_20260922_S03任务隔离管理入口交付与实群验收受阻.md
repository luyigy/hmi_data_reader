- `/ap isolation [status|on|off]`：默认关闭；任何群用户可查询，修改复用平台管理员配置，或通过飞书群信息接口验证群主/群管理员；权限接口失败时不修改设置。
- `/ap task new --title=任务名 --workdir=<目录>`：仅群根会话、模式开启时显式创建；验证目录存在，用户有授权根目录时限制在根目录内。保存请求后发送独立入口卡，读取真实 root/thread/chat 归属，原子绑定独立房间，最后更新卡片为就绪。
- `/ap task retry <请求ID>`：限定同应用、同群；复用请求、发送 UUID、卡片和房间。卡片发送响应丢失、根消息保存失败、卡片更新失败均可重试，不盲建新房间。飞书 UUID 去重仅一小时，因此请求超过 50 分钟且仍需外部发送时拒绝自动重发，交管理员核对原卡片。已保存根消息且已有话题的请求仍可恢复。
- 新任务不复制群历史、成员会话或权限。入口就绪后，在卡片话题使用已有 `/ap add --agents=local:codex` 添加成员，再连续聊天；不自动加入默认成员。卡片显示创建中、就绪或归档状态，归档后的普通输入仍由 S02 拒绝，retry 也不会恢复房间。归档后重试会刷新入口状态；卡片不是实时状态订阅。
- 关闭后禁止新建，既有任务继续走 S01/S02 话题映射，不改历史归属；重新开启复用原记录。普通群消息仍仅进入群入口。
