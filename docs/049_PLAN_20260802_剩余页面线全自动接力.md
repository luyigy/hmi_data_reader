# 049 剩余页面线全自动接力计划

## 1. 背景与授权口径

用户 2026-08-02 明确：「重新搞个计划，然后我们好跑自动化，就免得我一个个又来审查」。本计划把此前逐单元 PENDING_USER_APPROVAL 的节点全部改为自动默认裁决，用户仅保留事后否决权。已仲裁固化的自动化口径（013-048 全程沿用）：

1. **选机自动**：按 046 REPORT 矩阵与 `output/pages_pool_inventory.json` 附件量，取该家族附件量最大机台；不再等待候选批准。
2. **真值自动整批接受**（降级标注 + 用户事后否决权）；模糊/低质图直接拒识不入库。
3. **小批节奏**：单机 6 目标 + 2 候补，下载 8 张，每 turn 一个小步 + checkpoint `output/inj_progress.json`，长任务后台。
4. **硬门禁**：numeric ≥0.95、error =0、rejection =1 或 N/A；FAIL 即停报，如实记录转 SAFE_REJECT，**不追加调参死磕**；error=0 优先于 numeric。
5. **既有家族零 diff 红线**：任何新分支接入后，TACT/DEMAG/FANUC 已验收单元重提字段零 diff 才允许继续。
6. **断点续推**：服务重启/会话换代后从 checkpoint 幂等恢复，不重复下载与验收；HANDOVER 编号顺延。

## 4. 停止规则（自动化仍须刹车的情形）

- 硬门禁 FAIL：记录终态 SAFE_REJECT/FAIL 后**自动转下一单元**，不就地返工。
- 遇全新页结构/新家族且无对照模板：先 2-3 张摸结构再批量；仍不可判则记 NOT_APPLICABLE 转下一单元。
- 连续 2 个单元 SAFE_REJECT：暂停队列，如实报告等用户裁决（防系统性偏差空跑）。
- 环境阻塞（lark-cli 不可用等）：记 BLOCKED_EXTERNAL，本机环境正常即续推不等恢复。
- 任何需要生产写入/回填/push/重启的动作：一律停下来等用户。
