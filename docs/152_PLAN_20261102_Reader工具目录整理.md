## S01：整理工具并说明用途

- 目的：让使用者从目录理解工具职责，不再从阶段编号猜测用途。
- 完成后结果：保留工具按业务用途集中；每个源码目录有 README，列出文件作用、运行方式及副作用；顶层保留现有运行模块。
- 实现方法：按 AST 导入和路径依赖核对调用关系；删除 82 个已过期工具，移动 28 个可复用工具；同步测试、CLI 和仓库服务配置示例，保留既有数据位置与保护规则。移动文件数较多是一个模块路径迁移的原子改动，拆分会留下失效调用方；函数业务逻辑不扩展。
- 修改边界：Reader scripts、直接调用测试、当前 README、仓库服务示例和交接；不覆盖安装中的服务配置，不迁移 B&R 页面实现或冻结包源码。
- 验收：修改前 impact；完整保留测试、CPU 工具检查、CLI 帮助/导入、静态路径与 README 完整性；B&R 冻结包哈希和回放不变；git diff --check；提交前 detect_changes。
