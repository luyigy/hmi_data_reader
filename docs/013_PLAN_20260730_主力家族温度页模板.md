# 主力家族温度页模板建设计划

- 大表记录量（008 盘点）：**日精 1992 / 伯乐 1581 / 发那科 655 / 德马格 506** / 佳明 394 / 沙迪克 129 / 阿博格 117。
- 已核验机台-家族映射（`ground_truth/machine_labels.json`，王为核验）：日精=TACT×3 台（A06/B09/B10）、伯乐=KEBA×2（A01/B02）+B_AND_R×1（B01）、发那科=FANUC×1（A09）、德马格=DEMAG×2（A01/A02）。
- 007 S2 已验证这些家族的 record 级分类准确率 100%，缺的是**字段提取模板**。

## 2. 切片

### S1：矫正/质量门禁鲁棒性整改

**根因**：S3 中 4/18 张斜拍图四角检测失败被质量门禁拒在 OCR 前；另有段号小数字（HEADER_DIGITS）在低分辨率下识别不足。

**工作**：用 009 被拒的 4 张 + 各家族代表性斜拍样张组成校准集（与任何验收集隔离）；改进四角检测的 fallback 策略与质量门禁阈值；复核段号行放大策略。**只动 `scripts/rectify.py`、`scripts/quality.py` 等链路侧代码，不动任何已验收模板**；整改后佳明 holdout 作废不重测（009 规则），效果在校准集自测 + 后续家族验收中间接验证。

**停止条件**：校准集拒识率显著下降、无误放行恶化；改动固化新基线快照。

### S2/S3/S4：每家族同一套流程（TACT → KEBA+B_AND_R → FANUC+DEMAG）

1. 大表只读盘点该品牌记录，出候选清单（固定 seed、单机台上限），**用户批准后下载**。
2. VLM 预标注草稿 → 飞书核验表预填 → 用户概览核验 → 真值落盘（沿用 2026-07-30 简化口径并标注降级）。
3. 模板校准（归一化坐标，同 ZizES 0.2.0 做法）→ 链路跑一次 → 6 项指标报告。
4. 每家族独立验收：数值准确率 ≥95%、错误自动入库率严格 =0；失败则该家族另议，不阻塞后续家族。

## 5. S1 执行方式与基线发现（2026-07-30 修订）

- **执行方式**：S1 按小步接力执行——每个执行 turn 只完成一个可验证小步并即时提交，进度 checkpoint 落盘 `output/s1_progress.json`；任何 turn 中断后，后续 turn 读 checkpoint 续跑，不从头重做。（背景：单 turn 塞完整切片曾触发 1800s completion gate 超时。）
- **校准集**：`output/calibration_set_s1.json`（13 张，与任何验收集隔离）。
- **整改前基线**（`output/s1_calibration_pre.json`，跑分脚本 `scripts/s1_calibration_run.py --tag pre`）：13 张中 6 张红档被拒（拒识率 46%），构成 SCREEN_TOO_SMALL×3、SEVERE_PERSPECTIVE×2、SEVERE_GLARE×1；**13 张 rectify 四角分支全部成功、零失败**——当前代码下拒识全部来自质量门禁判定，整改重心为门禁逻辑（透视下屏幕尺寸低估误杀、透视/反光阈值），而非四角检测本身。整改后须人工核对被放行的原红档图确为可用图，防止误放行恶化。
