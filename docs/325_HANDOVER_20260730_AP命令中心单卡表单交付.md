### Workflow 与回调可靠性

- Workflow Dashboard “立即运行”等按钮会立即反馈已接收，完成后回复结果。
- Job 被停用后，即使已有调度请求在等待锁，也会在真正执行前再次检查并跳过。
- Card 2.0 即时更新返回完整 raw card，修复飞书 `200672`。
- 表单提交按钮使用 Card 2.0 `name` 与 `form_action_type: submit`，不再使用无效的顶层
  `value`。

### 权限展示与申请

- `/ap workflow policy show` 改为中文分区：结论、实际权限、隔离边界、只读目录、配置位置。
- `danger-full-access` 明确说明受外层 Bubblewrap 工作区沙箱约束。
- `/ap rights` 在命令中心显示为“权限申请”，结果明确为 Full Access（完全访问）权限申请。
- Full Access 批准前不会提升权限或启动新 Agent。

### 房间权限与角色

- “权限与管理”新增“权限约束…”：
  - 可选择当前房间全部 Agent 或一个指定 Agent；
  - 可选择 Safe Local（禁止网络）或 Dev Local（允许网络）；
  - 可写根目录被重置为当前房间工作区；
  - 权限先原子写入，再取消队列并停止旧运行，避免新 run 继续使用旧权限；
  - 不能真实执行 sandbox / writable roots 的 Harness 会整体拒绝，不会假装成功。
- 新增等价文本命令：`/ap restrict <agent-id|all> <safe|dev>`。
- “房间与 Agent”新增“设置角色…”：
  - 下拉选择 Agent；
  - 下拉选择 planner、researcher、implementer、reviewer、tester 或 custom；
  - 复用既有 `/ap role` 执行链。
