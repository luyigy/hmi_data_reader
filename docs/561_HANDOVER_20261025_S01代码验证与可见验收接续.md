## 做了什么与为什么

旧代码把普通卡片后台恢复挂在任务图展示 runner 上，图服务缺席时普通聊天无法补齐回执或终态。
现由聊天运行时负责启动、周期恢复和停止；图 runner 不再轮询普通卡片。

同时收紧卡片归属：真实执行绑定决定是否属于图，任务名前缀不能单独作决定。
普通卡片恢复使用共用展示器，图协议过滤仅在图通路包装器中执行。
统一外观、原卡 ID、权限入口和 Native Session 机制保持原有合同。

详细证据、限制和中间失败见 [560 验证报告](560_REPORT_20261025_S01聊天通路验证.md)。
