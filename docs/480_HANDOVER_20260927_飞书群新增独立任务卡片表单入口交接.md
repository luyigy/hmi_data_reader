# HANDOVER · 飞书群新增独立任务卡片表单入口交接

## 完成结果

在飞书群聊命令中心（`/ap help` / 房间菜单卡片）中增加“新增独立任务…”卡片表单入口（`form-task-new`），支持群成员通过卡片表单直接填写任务标题与工作目录创建独立任务。

主要改动与实现机制：
1. **表单入口展示**：在群聊场景的命令中心卡片中，展示“新增独立任务…”按钮（单聊场景保持隐藏）。
2. **表单提交与防重**：卡片表单提交按钮携带唯一 UUID 标识（`submitTask:<uuid>_group`），确保单次表单打开在重试或重复点击时具备稳定的请求身份，并由卡片回调处理程序解析映射回 `submitTask`。
3. **命令解析适配**：在 `buildFeishuCommandFromForm` 中支持对 `form-task-new` 提交数据的结构化解析，校验 `title` 与 `workdir` 字段并转换为 `{ command: 'task', args: ['new'], options: { title, workdir } }`。
4. **长连接卡片回调路由**：在 `feishu-long-connection.ts` 中注册 `form-task-new` 表单，兼容 UUID 格式的 action name 匹配，并向后续任务执行透传带有请求标识的 messageId。

## 修改文件与验证

- `src/lib/feishu-help.ts`：增加群聊“新增独立任务…”按钮、带 UUID 的表单提交名，以及 `form-task-new` 命令解析。
- `src/lib/feishu-long-connection.ts`：注册 `submitTask` 表单路由、正则兼容 UUID 提交动作名、组合生成唯一 messageId 并导出 `buildCardActionHandler` 供自动化测试。
