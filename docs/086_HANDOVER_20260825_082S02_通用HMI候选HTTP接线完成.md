# 082 S02 通用 HMI 候选 HTTP 接线完成

## 完成内容

- `POST /api/v1/draft` 原样返回 S01 的 `sections/questions`，不按 canonical hints
  二次过滤目录外字段，也不自动确认、写文件或落库。
- 保留 multipart 字段并增加可选 `ocr_evidence`；提供 evidence 时跳过 OCR，未提供时复用未修改的
  `recognize_image` 结果。两条路径都只调用一次 `draft_from_ocr`，并传入同一图片 bytes。
- 空文件和坏图片为 400，请求 JSON、上下文、hints 或 evidence 违反 S01 合同时为 422，VLM
  网络、输出 JSON 或 schema 错误为 502。
- OCR 与 VLM 分段使用既有单并发 semaphore，忙时为 429；Bearer middleware 和
  `/api/v1/recognize` 实现及响应合同未修改。
- 保护了开工前已有的 AGENTS、CLAUDE、TACT 路由、模板和测试修改，未纳入本 Slice。

## 请求字段

| 字段 | 必填 | 限制 |
| --- | --- | --- |
| `file` | 是 | 可解码的非空图片，最多 20 MiB |
| `target` | 是 | 非空，最多 200 字符 |
| `current_structure` | 是 | JSON object，最多 64 键；值为正整数 |
| `allowed_fields` | 是 | JSON array，最多 256 项；每项为 `field_id/label/unit/shape/role` |
| `message` | 否 | 最多 2000 字符 |
| `ocr_evidence` | 否 | JSON object；最多 2000 行，按 S01 的 `text/confidence/bbox` 合同 |

`shape` 仅为 `scalar/array`，`role` 仅为 `setpoint/actual/limit/unknown`。字段名
`allowed_fields` 暂时保留，但内容只是 canonical hints，不是输出白名单。

## 调用与响应

```bash
curl -X POST http://localhost:8000/api/v1/draft \
  -H 'Authorization: Bearer <token>' \
  -F 'file=@hmi.png' \
  -F 'target=normal_trial.holding' \
  -F 'current_structure={"holding_segments":2}' \
  -F 'allowed_fields=[{"field_id":"stage_holding_time_s","label":"保压时间","unit":"s","shape":"array","role":"setpoint"}]' \
  -F 'message='
```

失败响应分别为：


multipart 缺必填字段由 FastAPI 返回 422；OCR/VLM 都无候选时仍返回
`200 {"sections":[],"questions":[...]}`。
