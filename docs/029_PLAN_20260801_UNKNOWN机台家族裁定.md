# UNKNOWN 机台家族裁定计划（Backlog-B）

## 1. 背景

主力家族模板（TACT/KEBA/B_AND_R/FANUC/DEMAG）均按「机台级人工核验证据」路由（`ground_truth/machine_labels.json`）。尚有 29 台机台因无证据被排除在候选池外，其中发那科 Z036 有 474 条记录（比 Z032 的 81 条大近 6 倍），裁定后价值最大。

## 2. 切片

### S1：代表图抽取与下载

1. 汇总三份候选清单的 unknown_pending_decision（伯乐 `output/bole_expansion_candidates.json`、日精 S2 盘点、发那科 `output/fanuc_demag_candidates.json`）。
2. 每台取最新 1 条带「成型条件-炮筒温度设定」附件的记录，下载 1 张代表图到 `docs/samples_unknown/`，落 `output/unknown_sample_manifest.json`。

### S2：VLM 判族

逐图读屏判族（KEBA/B_AND_R/TACT/FANUC/DEMAG/ZIZES/其他/无法判定），输出 `output/unknown_family_drafts.json`（含证据描述与置信度）。

### S3：整批交用户裁定

建飞书核验表「UNKNOWN机台家族裁定」：每行机台、代表图、VLM 建议家族、确认列。用户一次整批裁定（本计划唯一人工门）。

### S4：回写与收口

裁定结果回写 `ground_truth/machine_labels.json`（verified_by=用户）；扩入候选池的机台另立 PLAN；HANDOVER 收口。

## 3. 停止规则

- S3 用户裁定前不做任何模板/池改动；S4 完成后停止，不自动启动新家族模板建设。
- 每 turn 一个小步 + checkpoint 到 `output/unknown_progress.json`；下载/建表后台跑。
