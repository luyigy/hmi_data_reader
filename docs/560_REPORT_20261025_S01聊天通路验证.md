## 遇到的问题及处理

- 图卡片回归使用真实账本绑定后暴露测试连接池限制：沙箱提供 `connection_limit=1`，
  图投递持有话题事务锁时，还需要独立连接保存发送意图，以保证发送错误回滚后回执仍在。
  未把独立回执塞入外层事务；仅为三项图卡片投递套件设置 3 条连接，覆盖两条并发投递和独立持久化。
  需要严格单连接的 `task-graph-review-publication` 继续保留 1。
- 原图发送夹具仅伪造任务名前缀，没有真实图绑定。现改成真实执行记录，并增加反向归属断言；
  展示断言相应包含已有的工作区详情面板。
- `live-room-steering` 旧夹具缺少普通卡片准备入口使用的 `findUniqueOrThrow` 和会话绑定查询。
  补齐无飞书绑定的聊天夹具，继续验证原有 steer/queue/session/generation 行为。
- 中间失败记录保留于 `2026-10-25T141850-929807`、`2026-10-25T142208-948330`、
