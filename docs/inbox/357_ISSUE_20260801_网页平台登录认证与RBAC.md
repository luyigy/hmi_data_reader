# ISSUE · 网页平台登录认证与 RBAC

- 本 ISSUE 只保留未纳入 352 的网页登录认证与权限需求；Inbox 快捷录入由 352 后续 Slice 处理。

## 需求与设计规范

当前网页平台（Web Dashboard）缺乏登录认证与权限鉴权系统，任何可以直接访问 HTTP 端口的客户端均可操作
平台 API 和房间控制台，存在严重的安全隐患。

### 网页平台登录认证系统（Authentication & Auth System）

- 引入用户身份认证机制（支持 Username/Password、Session Cookie、JWT Token 或与飞书/OAuth 身份集成）。
- 实施路由与 API 中间件保护（Auth Middleware），未登录未授权请求统一被重定向至登录页或返回
  `401 Unauthorized`。
- 建立角色权限模型（RBAC），支持管理员与普通用户权限隔离。

## 验收标准

- 未通过身份认证的请求无法访问网页控制台敏感操作及后台 API。
- 实施前单独完成威胁模型、全路由盘点、身份来源选择和 Session/Token 生命周期设计。

## 状态
