# Pi Agent 主机级供应商与模型切换 TODO

来源：2026-09-27～28，Live Room「Feishu DM 08a216」。仅登记候选需求，不启动实施工作流。

## 已讨论的范围

- AP 提供“选择主机 → 供应商 → 模型 → 应用”的网页入口及飞书卡片。
- 选择作用于该主机执行账户下、由 AP 启动的所有 Pi 房间；不新增房间级模型设置，不承诺改变账户外或手工启动的 Pi。
- 不强制依赖 CC Switch。首版沿用 Pi 原生供应商和凭据配置，AP 只负责选择与切换；新增供应商、密钥管理、模型发现后续独立评估。
- 每次新建或续接 Pi 都显式使用当前主机选择，覆盖本地与 SSH，避免旧会话恢复旧模型。
- 正在执行的请求保持当前配置，下一轮生效。显示期望配置与最近一次实际执行配置，不能把“已保存”当成“远端已应用”。
- 远端不可达、模型不存在、配置不可读时明确报未应用；重试和回退不能静默覆盖其他人的新设置。

## 工作量与边界

此前基于源码核查的初估，按一名熟悉项目的工程师、含开发测试：本机已配置供应商切换 1–2 人日；增加 SSH、飞书卡片、失败反馈和回退累计 3–5 人日；增加供应商管理、密钥管理、模型发现累计 1–2 周。不是排期承诺，远端版本差异和审计接入会影响估算。
