# TODO · AP 命令卡片增加角色工作流入口

## 待办

在 AP 命令卡片中增加“按各 Agent 角色分工完成任务”的入口，让用户无需记忆命令即可选择并启动对应模式。

当前版本对应的推荐用法：

- 日常使用 `hybrid` 模式。
- 功能任务使用 `/run feature <任务描述>`。
- 排障任务使用 `/run debug <问题描述>`。
- 仅当每条普通消息都需要自动经过角色队列时使用 `execution` 模式。

- 卡片沿用现有模式和命令能力，不新增另一套工作流协议。
