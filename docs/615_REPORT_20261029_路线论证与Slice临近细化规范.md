# 路线论证与 Slice 临近细化规范

2026-10-29，Feishu DM 08a216。用户要求先确定有依据的总体路线，Slice 初定，真正实施前再详细规划；在明确修改范围后授权“那就改”。

## 已落实的规则

1. 初始路线明确目标、非目标、架构方向、阶段结果、整体验收标准、关键假设及论证依据。对足以推翻路线的未知做必要的最小实验，已有充分证据可直接引用。
2. 初步 Slice / ticket 说明问题、可验证结果、边界、预计前置和未决问题，不要求提前写完远期文件清单、函数设计和精确测试命令。
3. 当前片编码前先读取最新代码、前片交付和验证证据，核对假设，再记录实现、修改范围、验证与停止条件。使用现有票或执行记录，不强制另建文档或再开审批阶段。
4. 每片交付记录实际结果、与原设想的差异、假设变化及后续影响。按可验证结果切片，允许贯通必要技术层，不按固定文件数量机械拆分。
5. 原目标、权限和验收要求内的实现细化直接推进；路线、依赖或授权的实质变化按既有流程修订后生效。保留批准快照与已完成证据。
