# TACT5 争议十框原生像素定标

选择方案①：由 Codex 给出坐标，交 kimi-code 写回。交接清单实际为10框（0904五框、03一框、0903三框、0912一框），不是约8框。本轮已查看10张原生三联证据，建议框完整包含相应数值字形；尚未写回训练答案，不能称为最终框验收。

## 方法与证据

直接读取 manifest 原图，EXIF 转正，裁剪保持1:1原生尺寸。先在带原图像素刻度的裁剪定位字形，再将像素框按 x/宽×100、y/高×100 换算到百分比（保留3位小数）。无透视拟合、无自动吸附、无展示尺寸反算。重新从百分比反投影绘制红框，逐项查看清洁图／当前框／建议框三联；定位以完整数值字形为目标，不要求覆盖整个输入槽外框。

证据目录：[tact5-coordinate-proposal-20260927](../output/training-prep/tact5-coordinate-proposal-20260927/)。`*-ruler.png`为4张原生刻度裁剪；`*-proposal.png`为10张三联证据；`proposed-boxes.json`含准确字段键、旧框、像素框、新框；`provenance.json`含5份答案SHA256与原图SHA256、尺寸。
