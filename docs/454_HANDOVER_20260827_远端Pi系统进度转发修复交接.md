# HANDOVER · 远端Pi系统进度转发修复交接

## 结果

远端 SSH Pi 的 assistant 文本现已进入既有 stdout/system 进度链路。飞书进度卡的
「系统信息详情」会随 `message_end` / `turn_end` 更新，同时最终回复仍只返回一次；工具事件路径不变。

## 根因与修复

- `src/lib/remote-harness/ssh-executor.ts` 的 Pi JSON 分支只把 assistant 文本保存为最终
  `resolvedText`，没有调用 `onStdoutChunk`，导致工具详情持续更新而系统详情停在启动行。
- `processPiJsonLine` 现在复用同一份已解析文本调用 `onStdoutChunk`，避免在上层两个读取路径重复补丁。
- 新增 `tests/remote-ssh-pi-progress.test.ts`，用伪 SSH 流同时锁定工具回调、系统文本回调和最终输出。
