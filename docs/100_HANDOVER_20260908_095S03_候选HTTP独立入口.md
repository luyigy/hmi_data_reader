## 请求与响应例子

图片单独请求（示例命令，未执行）：

```bash
curl http://localhost:8000/api/v1/draft \
  -H 'Authorization: Bearer <token>' \
  -F 'file=@hmi.png'
```

继续支持 `-F 'target=normal_trial.holding' -F 'current_structure={"holding_segments":3}' -F 'allowed_fields=[]'`；可选 `-F 'mode=ocr_text'` 和 `-F 'ocr_evidence={"lines":[{"text":"冷却时间 3 s"}]}'`。字段名 allowed_fields 只是历史名称，语义为 canonical hints。

响应仍为 S02 `sections/questions`，无 HTTP 包装或自动确认。结构示意（不是本轮模型测量）：

