# TACT 温度页模板校准与链路验收计划

- `ground_truth/tact_temperature/` 已有 6 份 Z022/A06 真值，`changed_fields=0`；rank03 的斜拍反光及落下口设定 50.0 已复核。

本 PLAN 将上述确认视为已完成事实，不重新发起讨论或核验。

## 2. 必要技术边界

当前 `scripts/extract_fields.py` 的温度页提取逻辑按 ZizES 的 7 段料筒加油温布局写定，`scripts/verify_accuracy.py` 的数值字段清单也只覆盖 ZizES 字段。TACT 真值另有：

- `holding_temperature_c[5]`
- `drop_port_temperature_set_c`
- `drop_port_temperature_current_c`
- `drop_port_control_percent`

因此只增加 `templates/tact.temperature.json` 不足以完成验收；S1 必须同步做最小的 TACT 提取和验证适配，并保持 ZizES 行为不变。

## 3. 切片

### S1：模板与最小链路支持

1. 基于 6 张已核验图校准 `templates/tact.temperature.json`，使用 `scripts/rectify.py` 输出屏幕的归一化坐标。
2. 在既有加载、路由和提取入口内增加 TACT 分支，覆盖 5 段料筒、保温温度和落下口字段；不为单一家族引入插件、工厂或新配置层。
3. 让六指标验证器按对应真值 schema 统计 TACT 数值字段，防止只算 ZizES 字段形成假高分。
4. 对模板加载、TACT 数值字段分母、关键词碰撞和 ZizES 不退化做聚焦检查。

**停止条件**：TACT 模板与字段支持完成，聚焦检查通过并创建 S1 HANDOVER；不得在本 Slice 运行最终六图验收。

### S2：六图一次性链路与报告

1. 从 `ground_truth/tact_temperature/*.truth.json` 的 `image` 精确选出 6 张已核验目标图，建立隔离的运行输入；不得把 `docs/samples_tact/` 中 4 张候补混入验收分母。
2. 只运行一次完整链路：去重 → 质量门禁 → 矫正 → OCR → 控制器/页面分类 → 字段提取 → 真值比对。

4. 创建 S2 HANDOVER，记录 PASS/FAIL、降级口径及后续决策；不得自动启动伯乐或其他家族工作。

**停止条件**：六项指标报告与 S2 HANDOVER 已落盘，结论按本 PLAN 门槛明确判定后停止。

## 4. 验收口径

六项指标沿用现有 `scripts/verify_accuracy.py` 定义：

1. 控制器分类准确率
2. 页面分类准确率
3. 字段完整率
4. 数值准确率
5. 可自动入库比例
6. 错误自动入库率

本阶段硬门槛：

| 指标 | 门槛 |
|---|---:|
| 数值准确率 | ≥ 95%（误差容限 ±0.5） |
| 错误自动入库率 | 严格 = 0 |

若没有任何 `status=ok` 字段，错误自动入库率不得以空分母记为 0 或 PASS。其余四项必须如实报告，不另加未获批准的新门槛。

1. 用户的整批确认有效；无需逐项复制粘贴，`changed_fields=0` 与降级核验方式继续保留。
2. 当前验收集固定为 6 张 Z022/A06 图片；候选池只有一台机的结构性降级必须写入报告。

## 6. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 6 张图均来自 Z022/A06，无法证明跨机台泛化 | 报告明确限定为单机台 PoC；B09/B10 或其他机台另行立项验收 |
| 真值采用整批概览确认，存在锚定风险 | 保留 `visual_skim_acceptance` 降级说明；不得把结论表述为独立盲标 |
| 校准集与验收集是同一批 6 张图，指标不能代表盲测泛化 | 只声明模板链路可运行，不声明泛化或生产可靠性 |
| TACT 特有字段被验证器漏算会制造假高分 | S1 要求全部真值数值字段进入分母，并留最小自动检查 |
| TACT 关键词污染其他家族路由 | S1 做全库关键词碰撞检查，并复核现有 ZizES 样本不退化 |
| 保守门禁可能使全部图片无 `status=ok` 而出现假零错 | 空分母一律 FAIL，同时报告可自动入库比例和缺失提取 |
