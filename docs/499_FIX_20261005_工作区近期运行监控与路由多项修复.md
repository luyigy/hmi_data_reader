# FIX · 工作区近期运行监控与路由多项修复

## 概述与背景

本轮提交将工作区中累积的多项针对飞书看板、任务路由、长任务心跳反馈、看门狗保护及 Kimi 模型目录的运行修复进行统一收敛、验证与提交。

## 修改内容清单

### 1. 飞书工作流看板紧凑模式与草稿过滤
- **涉及文件**：
  - `src/lib/feishu-scheduled-jobs.ts`
  - `src/lib/scheduled-jobs/workflow-dashboard-document-forms.ts`
  - `src/lib/scheduled-jobs/workflow-inspection.ts`
  - `tests/feishu-job-command.test.ts`
- **改进点**：
  - **紧凑模式（Compact Mode）**：当文档总数（Inbox + PLAN + HANDOVER + 其他）> 15 时，自动启用 compact 布局（Inbox 1 篇、PLAN 2 篇、HANDOVER 3 篇、其他 1 篇，提审下拉列表倒序取最近 5 个），防止历史文档较多时飞书卡片体积超过飞书单卡限制导致渲染失败；并在卡片底部提示使用 `/ap md` 或 `/ap doc` 查看全部。
  - **草稿交接过滤**：在 `inspectWorkflowOverview` 解析每个 PLAN 关联的 HANDOVER 时，过滤掉 `metadata.doc_status === 'draft'` 的草稿文档，避免未定稿文档干扰切片完成状态判断。
  - **切片标题序号兼容**：正则扩展为支持带编号前缀的切片标题格式（如 `## 1. S01: xxx`）。

### 2. Kimi Code 本机模型目录查询与命令集成
- **涉及文件**：
  - `src/lib/real-agents/kimi-code-model-catalog.ts`（新增）
  - `src/lib/feishu-live-room-commands.ts`
  - `src/lib/feishu-help.ts`
  - `tests/kimi-code-model-catalog.test.ts`（新增）
- **改进点**：
  - 新增 `listKimiCodeModels(cwd)`，通过执行 `kimi provider list --json` 读取已配置模型、展示名及思考档位能力（`supportEfforts` / `capabilities`）；
  - 在 `/ap model-config --agent=<kimi> --list` 中开放 Kimi 成员本机模型目录查询，并在帮助与输出中提示 Kimi 目前仅支持 `--model`，暂不支持 `--thinking`。

### 3. 长时间执行心跳反馈
- **涉及文件**：
  - `src/lib/live-room-progress.ts`
  - `src/lib/live-room-raw-output.ts`
  - `tests/live-room-raw-output.test.ts`
- **改进点**：
  - 在 `attachLiveRoomStructuredOutput` 中增加 `onHeartbeat` 回调机制，每两个心跳周期（约 90 秒）触发一次；
  - 向 Live Room 发送系统提示消息：`系统提示：${participant.displayName} 仍在处理中，当前步骤耗时较长。`，避免长耗时任务在群内无可见反馈导致用户误判为卡死。

### 4. Live Room 定向接力路由保护
- **涉及文件**：
  - `src/lib/live-room-delivery-routing.ts`
  - `src/lib/live-room-protocol.ts`
  - `tests/live-room-directed-protocol.test.ts`
- **改进点**：
  - 操作手册明确声明：仅当最新指令明确要求该成员立即行动时才进行交接；对于自然语言中提到未来工作的指令（如“之后再考虑 B”），当前成员回复后应停止，不得自动触发交接；
  - `inferDirectedVisibleRelayTargets` 仅对显式提及（`explicitMentions.matchType === 'explicit'`）触发接力，避免非显式提及的文本误触发后续 Agent 执行。

### 5. 本机看门狗长任务清理保护
- **涉及文件**：
  - `src/lib/feishu-runtime-cleanup.ts`
- **改进点**：
  - 在 `startPeriodicWatchdog` 中，放宽 `isPlatformLocal` 判断至所有 `platform_local` 成员；
  - 增加 `hasLiveRoomMemberExecution(delivery.targetMemberId)` 保护：只要该成员在本地执行注册表中仍处于活跃执行状态，就不将其判定为 stale 或强行回收。

### 6. 测试用例与治具维护
- **涉及文件**：
  - `tests/fixtures/workflow-watcher-contract.ts`（新增）
  - `tests/workflow-watcher.test.ts`
- **改进点**：
  - 将 `workflow-watcher.test.ts` 内大段内嵌的 workflow contract 文本抽离至独立 fixture 文件，优化测试维护性并确保测试文件行数严格在长文件阻断线以下。

### 7. 运行环境配置同步
- **涉及文件**：
  - `config/runtime-environments.json`
- **改进点**：
  - 同步记录工作区新增 session 路径映射。
