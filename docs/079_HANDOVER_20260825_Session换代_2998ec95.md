## 已完成

- `draft_from_ocr` 接收 OCR evidence、用户消息、目标页、当前结构和字段白名单。
- VLM 请求只包含清洗后的 OCR 行及调用方上下文，不包含页面分类或数据库路径。
- 响应只接受白名单 `field_id`，单位必须与白名单一致，值必须匹配 scalar/array shape。
- evidence 必须逐字引用完整 OCR 行；重复字段、非有限数、非法结构建议和坏 JSON 均拒绝。
- 空 OCR 不调用 VLM，保守返回空候选和重拍问题。
- 聚焦测试覆盖白名单、标量/数组、用户纠正、证据引用、空 OCR 和非法 VLM JSON。
