# 225_DECISION_20260725_文档自动化状态机

## 决策

用“文档类型 + YAML 控制字段 + 精确 Prompt 标记”驱动连续 Slice，取代仅按
文件类型或正文猜测下一步的方式。本决策取代
`111_DECISION_20260721_计划与交接触发规则.md` 中“任何文档都不得自动创建
Session”的约定。

自动化仍不能自行规划新阶段：阶段计划完成后必须停止并通知用户验收；总体路线
中的下一阶段需要人与 agent 共同制定、修订并批准新的阶段 PLAN。

## 文档语义

| TYPE | 语义 | 自动化 |
| --- | --- | --- |
| `ROADMAP` | 总体路线、阶段顺序和验收后的阶段状态 | 永不直接启动 Session |
| `PLAN` | 阶段多 Slice 计划，或阻塞 bug 的嵌套计划 | 仅 ready + `start_first_slice` 可启动 |
| `HANDOVER` | 一次 Session 的事实记录和受控转换 | 仅 `next_slice` / `resume_parent` 可启动 |
| `DECISION` | 已接受的规则 | 不启动 |
| `ISSUE` | bug 证据、调查或队列项 | 不启动 |
| `REPORT` | 验收、里程碑、进度或验证结果 | 不启动 |

本仓库既有文档继续按原名称保留，本次不为统一历史命名制造大范围链接变化。

## 控制字段

参与自动化的 PLAN/HANDOVER 在文件首部写 YAML：

```yaml
---
doc_type: HANDOVER
doc_status: completed
plan: 147_PLAN_YYYYMMDD_阶段计划.md
slice: S01
plan_progress: in_progress
next_action: next_slice
---
```

可执行的 `next_action` 只有：

- `start_first_slice`
- `next_slice`
- `resume_parent`

停止并通知的 `next_action`：

- `await_plan_approval`
- `await_acceptance`
- `blocked`
- `none`

只有可执行 action 才允许在文末出现一次
`WORKFLOW_PROMPT_START / WORKFLOW_PROMPT_END` 标记。非可执行 action 禁止携带
Prompt，cron 不得从自然语言推断意图。

## 阶段计划生命周期

```text
PLAN draft
  └─ await_plan_approval → 人工修订/批准

PLAN ready
  └─ start_first_slice → Slice 1 HANDOVER
       ├─ next_slice → 下一 Slice
       ├─ blocked → 通知并停止
       └─ 最终 Slice: await_acceptance → 通知用户实际验收并停止

验收通过
  └─ 更新 ROADMAP → 人机共同制定下一阶段 PLAN
```

阶段 PLAN 必须提前定义 Slice 顺序、每个 Slice 验收、计划级完成条件、最终需要的
人工验收和停止条件。最终 Slice 不生成下一实施 Prompt。

## Bug 分叉与返回

- 为达到当前 Slice 验收所必需、影响明确的小 bug，可在当前 Session 内修复并写入
  同一 HANDOVER。
- 不阻塞当前 Slice 的 bug 写入 ISSUE 或 Bugfix Queue，不打断主线。
- 大型阻塞 bug：父 Slice 写一次 paused HANDOVER，再创建
  `plan_kind: interrupt` 的嵌套 PLAN；必须记录 `parent_plan`、
  `parent_slice` 和 `return_to`。
- 嵌套 PLAN 最终 HANDOVER 使用 `resume_parent` 返回精确父 Slice；不得按“最新
  PLAN”猜返回点。
- 未被当前用户指令预先授权的嵌套 PLAN 默认为 `await_plan_approval`。

## Cron 安全门禁

Cron 必须：

1. 只读取配置分支上已经提交的文档内容，不读取工作区半成品；
2. 校验文件名 TYPE、YAML、引用 PLAN/Slice、action 与 Prompt 标记一致；
3. 用 `(commit, path, blob hash)` 做一次性处理账本，避免每十分钟重复启动；
4. 仅对三个可执行 action 创建一个 Session；其他 action 只通知；
5. 元数据缺失、冲突或引用不存在时停止并通知，不回退到猜正文；
6. 阶段完成后不得从 ROADMAP 自动创建下一 PLAN。
