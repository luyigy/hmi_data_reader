# HANDOVER · S01 380 P0 Workflow 编排失败错误分类

## 完成内容

修改 `src/lib/live-room-workflows.ts` 中 `runLiveRoomPlan` 的错误处理，消除笼统
"PLAN 未提交"提示，实现四类失败差异化：

### 新增

- **`WorkflowPlanError`** 错误类，携带 `category`（`member_execution` / `plan_path` /
  `git_commit` / `unknown`）、`detail`、`stageLabel`、`memberName` 字段。
- **`filterDiagnosticNoise`** 辅助函数，匹配 `tcmalloc`、`jemalloc`、`libnuma` 等
  无害 stderr 行，将其从主错误文本分离至"诊断详情（stderr）"。

### 修改点

| 位置 | 原行为 | 新行为 |
|---|---|---|
| `runStage` 的 throw | 通用 `Error`，信息丢失 | `WorkflowPlanError` + `member_execution`，携带 `output` 详情 |
| PLAN_PATH 检查 | 通用 `Error` | `WorkflowPlanError` + `plan_path` |
| Git 调用 | `execFileAsync` 异常穿透到 catch | 包装为 `WorkflowPlanError` + `git_commit`，含 stderr |
| catch 块 | 统一"PLAN 未提交" | 按 category 分发四套差异化提示，含失败阶段/成员/影响/处置引导 |

### 四类失败提示对比

| 失败类型 | 提示示例 |
|---|---|
| 成员执行失败 | `⚠️ PLAN 编排已暂停` + 失败阶段/成员 + 诊断详情（stderr 分离） |
| PLAN_PATH 不合法 | `⚠️ PLAN 编排已暂停` + 原因 + 处置 |
| Git 提交失败 | `⚠️ PLAN 编排已暂停` + git 错误 + 建议检查 git status |
| 未知错误 | 保留 `系统提示：PLAN 未提交：...` 兜底 |
