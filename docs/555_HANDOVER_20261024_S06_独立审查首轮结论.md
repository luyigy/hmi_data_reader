**P2，S02 部分实现：显式 DATABASE_URL 仍受不可读的 .env 阻断。**

- 依据：545 PLAN 第 70 行要求“修测试脚本显式配置的读取顺序”。
- 位置：`scripts/test-task-graph-postgres.mjs:12` 先读取 `.env`，第 13 行才选择显式 URL。
- 触发：已提供显式 URL，`.env` 存在但当前用户不可读，读取先抛 `EACCES`。
- 当前改动解决了 `.env` 不存在时的失败，但没有让显式配置短路回退文件读取。
- 最小修正方向：仅在没有显式 URL 时读取可选 `.env`；保留 loopback、随机 schema 等已有约束。

独立审查者已用真实文件系统执行下面的表达式探针：UID 1000，临时文件权限 000 时复现 EACCES；
仅改为 600 后同一表达式选择显式 URL 成功。探针退出 0、临时目录删除，未连接数据库。
这是固定源码两行表达式的动态验证，不冒充完整 runner 回归。
首轮探针曾因复用 vm context 重复声明变量而失败；最终每次 fresh context，夹具错误不计为产品红色证据。
