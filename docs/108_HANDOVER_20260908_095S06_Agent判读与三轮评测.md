## 标注与评分边界

- `artifacts/095_s06_agent_reference.json`：5 张原图路径和 SHA256、78 项可判读关系、10 个未解项/组及原因、显式字段语义别名。来自温度、保压、模温、热流道和注射原图。
- 先目视读取原图，再检查已有候选及定义语义别名；这是一份开发参考标注，非双盲评测。三轮新请求输出读取前固定别名表，评测过程中不修改。
- 不以候选列表生成真值。注射图明确有压力 65/100、速度 12/0/25/75、位置 17.50/0/22.50/45；保压压力行有两个 0，重复值不能合并。热流道区号来自面板实体标签，℃ 来自数码管右侧指示。
- 无文字段号的表格以画面列位置标记，不冒充物理段号；预测中空 label 不按数组顺序补齐。只允许已有明确温区 section 标签转成 label。空单位转 null，不补预测单位或角色。
- 模温设备 PV/SV 均 30，画面未核实单位，参考单位为 null；两项匹配不能证明温度标准化映射完成。热流道第 6 路屏幕黑屏，不编造温度或计为数值漏项。
- 保温小字、无文字图标组、保压表格首列深色值角色、底栏计时含义列为 unresolved。未解组不是单元格计数。日期、页码、图轴刻度、开关状态和印刷错误码排除在数值工艺关系范围外。
- 现有评分器将未解参考排除于召回分母，未匹配候选仍计入 FP。因此含 unresolved 类别的 precision 是保守匹配比例，**不是全图准确率**；不能把这些 FP 全部称作已证实错误。可判读子集的召回与逐项错配可复核。
- 每条归一参数名加图片序号前缀，防止不同图片同值关系相互抵消；预测保留原响应 section/field/item 索引。原始结果一并保存，可追溯归一判断。

## 已能确认的错误

1. 温度图：顶针位置原图 -0.8，被读为 -0.3；加热输出 #1 原图 56.6，被读为 56.5。保温小字暂不裁决，不把它算作已证实数字错误。
2. 保压图：左侧实际切换/保压/位置/余料量四项均给 unknown；可辨认的设置行也给 unknown 且没有列位置。压力行两个 0 被缩成一个，说明重复值丢失。首列深色单元格是否属于设定不在本轮强行裁决。
3. 热流道图：十项温度数值、PV/SV 角色及控制器号正确，但可见 ℃ 全部漏提，因此五维严格匹配为零，不能解释成十项数字都错。
4. 注射图：将速度行 25/75 放到压力，将位置行 22.50/45 放到速度；漏压力 100，偏差限制的正负两个零只留一个，无列位置。底部“冷却”是状态文字，却与 0 mm 绑定成参数；这不能冒充已识别冷却时间。
