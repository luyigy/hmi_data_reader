# PLAN · 服务重启后角色串行终态复验

## S01：无改动角色接力复验

服务重启后，用新的 workflow event 复验 PLAN 是否自动进入现有角色串行流水线，不实施业务功能。

验收范围：

- 系统依次展示实施计划、计划审查、计划定稿、测试方案、功能实施、代码审查、验收测试、最终总结 8 个阶段。
- 每个阶段显示的执行成员与房间角色匹配，不能由同一成员代跑全部阶段。
- 计划审查和代码审查仅输出 `APPROVED`，验收测试仅输出 `PASSED`，功能实施输出 `NO_CHANGES` 和“修改文件：无”。
- 成功时 dispatch 进入 `completed`；任一阶段失败时 dispatch 进入 `failed`，停止且不再等待后续角色。

禁止修改文件、提交 Git、重启服务或执行耗时测试。任一阶段失败、顺序或角色不符、需要手动启动工作流，均停止并报告实际阶段与成员。
