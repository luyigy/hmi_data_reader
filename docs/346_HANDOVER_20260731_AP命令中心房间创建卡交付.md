## 回调超时修复

首次实现在线同步调用 `listLiveRoomCatalogAgents()` 枚举 Agent。实测 27 个 Agent 的探测耗时约 4.03 秒，超过飞书卡片回调窗口，客户端显示“回调服务器超时”。

修复后：

- Feishu Runtime 长连接启动后后台预热 Agent catalog；
- 卡片点击只读取进程内缓存，不再等待实时 Agent 探测；
- 冷缓存时 3ms 内返回“Agent 列表正在加载，请稍后重试”；
- 热缓存时约 10ms 返回完整表单，包含 27 个 Agent 选项；
- 真正提交 `/ap room` 时仍走既有实时 Agent 解析和校验，缓存只服务表单展示。
