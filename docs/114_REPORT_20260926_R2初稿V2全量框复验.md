## 范围、方法与可复验性

对象为 `output/training-prep/annotation-draft-20260926-r2/` 当前 16 份 JSON，合计 **539 字段、68 个 null、519 个 bbox、20 个无 bbox 的 null**。

逐一打开查看了全部 519 个 bbox 的带上下文裁剪，共 37 张证据页；红线是当前 v2 坐标，不是建议修订框。字段序号沿用 JSON 的插入顺序（包括无 bbox 字段），每格同时列出键名、value、unit 和 bbox。`03830ab4`、`f627d3c0` 先按 EXIF 转正再使用百分比坐标。重点分歧另查看原始分辨率上下文图。没有使用 OCR 输出代替视觉复核，也没有改变原图像素文件。

验收标准：至少完整覆盖目标数字/文字，不能仅凭局部字形猜值；null 槽应定位到对应槽，不能跨到邻行。明确错位、截字归为 `redraw`；贴线、轻微截笔疑点或空槽边界不完整归为 `boundary_recheck`；剩余 `no_obvious_issue` 表示此次逐框查看未见明显问题，不是精确像素真值或人审批准。
