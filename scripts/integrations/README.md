# integrations 目录说明

与外部系统交互的入口。核心识读仍调用公共 Reader 链路，页面算法不放在这里。

| 文件 | 作用与执行影响 |
| --- | --- |
| `feishu_card_assistant.py` | 飞书互动卡片、图像处理和 webhook 入口；--send 或表格同步会产生真实外部写入，需要明确授权。 |

`__init__.py` 仅标识 Python 包，不启动任务。推荐从仓库根目录使用 `python -m scripts.integrations.<模块名>`；有命令行参数的工具可先查看 `--help`。多数工具也支持直接执行文件。不要用“导入所有模块”验证这些工具，部分既有程序会在导入时读取本地实验输入。
