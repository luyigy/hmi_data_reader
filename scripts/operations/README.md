# operations 目录说明

离线流水线与页面管理命令。模板发布、生命周期写入和模型调用都是显式操作；这不是自动恢复旧页面的调度器。

| 文件 | 作用与执行影响 |
| --- | --- |
| `manage_page_templates.py` | 页面模板草稿、试跑和发布的本地操作入口；save/publish 会写 Reader 模板及注册状态。 |
| `profile_lifecycle.py` | 查看和操作页面生命周期；默认预演，--apply 才写状态，不绕过页面接纳规则。 |
| `run_pipeline.py` | 离线串联去重、质量、矫正、OCR、分类、可选提取和真值比较；OCR 可加载模型，输出写入指定目录。 |

`__init__.py` 仅标识 Python 包，不启动任务。推荐从仓库根目录使用 `python -m scripts.operations.<模块名>`；有命令行参数的工具可先查看 `--help`。多数工具也支持直接执行文件。不要用“导入所有模块”验证这些工具，部分既有程序会在导入时读取本地实验输入。
