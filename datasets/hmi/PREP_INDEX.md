# 训练集准备索引（活文档）

用途：按机台×页面跟踪训练数据准备进度，每批在飞书任务话题确认后打勾。维护者：$lkc（kimi-code）；确认方式：聊天群内逐图裁定（hmi-review-pair 对照图）。
最近更新：2026-09-28。

## 文件结构约定

| 路径 | 内容 |
| --- | --- |
| `datasets/hmi/raw/feishu/<日期>/<品牌>/<机台>/` | 未改动的原图，含来源 manifest |
| `datasets/hmi/annotations/<批次>/<图片ID>/` | 每张图一个目录：`image.*` + `annotation.json`（answer.fields 含 value/unit/kind/bbox） |
| `datasets/hmi/catalog/` | 训练/验证/测试清单与全库索引 `images.jsonl` |
| `templates/` | 各品牌×页面模板（提取口径参考） |
| `output/reviews/<批次>/` | 对照图、裁定记录、复现脚本等复核证据 |

集合规则：**同一机台+模具+日期为一组，整组进同一集合（train/val/test），禁止拆组**。bbox 为未 EXIF 转正的原生像素百分比 xyxy。

## 页面类型编码

- A 射胶/保压（含 V-P 切换）
- B 储料/松退/熔胶
- C 炮筒温度
- D 模温机（温控器/温控箱）
- E 热流道温控箱
- F 波形/成型监视（暂缓）
